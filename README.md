## About Me

Full-Stack Software Engineer with **3+ years** of professional experience building production-grade web and mobile applications. I specialise in **JavaScript/TypeScript**, **React.js**, **Vue.js**, **Node.js**, and **Python FastAPI**, with deep expertise in REST API design, OAuth 2.0, real-time systems, Redis caching, Docker, and Linux VPS deployment.

- Currently a **Software Engineer @ Core Devs Ltd.**
- Delivered **10+ production projects** across fintech, e-commerce, HR, Web3, and social media
- IEEE Published: *Vehicle Routing Problem Solving Using Reinforcement Learning* — [ICCIT 2023](https://ieeexplore.ieee.org/document/10441644/)
- Passionate about **clean architecture**, **developer experience**, and **UX-first design**
- Fun fact: I play guitar and live with a very opinionated cat
